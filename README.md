# Media-Converter-App

A gift for my grandfather, so that he could convert any legacy media file to current media format file.

A simple Android app built with .NET MAUI to convert legacy audio and video files
into modern, shareable formats using FFmpeg.

## Features
- Audio → MP3
- Video → MP4
- Offline conversion
- Simple UI

## Download
See the **Releases** section to download the APK.

## Tech Stack
- .NET MAUI
- Android
- FFmpegKit
